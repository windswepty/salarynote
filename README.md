# 샐러리노트 (salarynote)

한국 직장인용 급여 계산기. 정적 사이트이며 모든 계산은 브라우저에서 처리된다(서버 없음).

## 구조

```
data/     요율·세액표 원장. 숫자는 전부 여기에만 있다.
src/      계산 엔진 (CommonJS, 브라우저와 테스트가 공유)
test/     순수 node + assert. npm 의존성 없음.
build/    브라우저 번들러 / 배포 주소 설정
web/      배포되는 정적 파일
```

## 원칙

1. **숫자를 코드에 하드코딩하지 않는다.** 전부 `data/*.json` 에서 읽는다.
2. **검증되지 않은 숫자는 넣지 않는다.** 법령 원문(law.go.kr)을 정본으로 하며,
   국세청 안내 웹페이지는 구버전을 노출하는 경우가 있어 근거로 삼지 않는다.
3. **조용히 틀리는 것보다 멈추는 것이 낫다.** 입력 검증에 실패하면 예외를 던진다.
4. 계산 결과에는 항상 근거(basis)를 함께 반환해 화면에 노출한다.

## 명령

```bash
node build/bundle.js                    # web/assets/engine.js 재생성
node build/set-base-url.js <URL> <이메일> # canonical/sitemap 주소 확정
for f in test/*.test.js; do node "$f"; done   # 전체 테스트
```

`web/assets/engine.js` 는 생성물이지만 배포 안정성을 위해 커밋한다.
원본과 어긋나면 `test/bundle.test.js` 가 실패한다.
